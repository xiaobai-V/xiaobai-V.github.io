二分查找属于那种原理很简单，但是细节处理很麻烦的算法，下面用一种**红蓝边界法**的模板作为通解处理各种二分查找的问题。

## 方法介绍：

### 算法：二分红蓝边界查找
**输入**：范围上限 $N$，布尔判定函数 $\text{isBlue}(x)$
**输出**：边界下标

1. 设定初始区间：$l=-1,\ r=N$
2. 循环条件：$l+1 \ne r$
3. 计算中点：$m = \dfrac{l+r}{2}$ 向下取整
4. 若 $\text{isBlue}(m)$ 成立，令 $l=m$
5. 否则令 $r=m$
6. 循环结束，返回 $l$ 或 $r$

### 原理
区间始终保持**左蓝右非蓝**，最终两指针相邻，$l$ 是最后一个合法蓝点，$r$ 是第一个非蓝点。
## 例题

### 例题一

[34. 在排序数组中查找元素的第一个和最后一个位置 - 力扣（LeetCode）](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/description/)

```cpp
class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        // 红蓝标记法
        // 开始位置：>= target 第一个元素
        // < target 左侧; >= target 右侧；返回right
        int n = nums.size();
        int left = -1, right = n;
        while (left + 1 != right) {
            int mid = (left + right) >> 1;
            if (nums[mid] < target) {
                left = mid;
            } else {
                right = mid;
            }
        }
        int startIdx = right;
        // 结束位置：<= target 第一个元素
        // <= target 左侧； >= target 右侧；返回left
        left = -1, right = n;
        while (left + 1 != right) {
            int mid = (left + right) >> 1;
            if (nums[mid] <= target) {
                left = mid;
            } else {
                right = mid;
            }
        }
        int endIdx = left;
        vector<int> res = {-1, -1};
        if (endIdx >= startIdx) {
            res[0] = startIdx;
            res[1] = endIdx;
        }
        return res;
    }
};
```
