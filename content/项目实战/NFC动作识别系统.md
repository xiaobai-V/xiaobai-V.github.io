# NFC 动作识别系统

## 做了什么

利用无源 NFC 标签在空间中运动时负载调制信号的变化，实现低成本动作识别。
标签成本极低，不需要电池。

## 系统架构

```
NFC Tag (无源) ←→ Reader (PN532) → 模拟信号放大 → STM32 (ADC) → 特征提取 → 动作分类
```

## 技术细节

### 信号采集

NFC 标签在不同距离和角度下，负载调制信号的幅度和相位会变化。通过 Reader 采集 RSSI 和信号质量指标作为原始数据。

### 特征工程

- **时域**：均值、方差、过零率
- **频域**：FFT 主频、能量分布
- **波形**：上升/下降沿特征

### 分类

- 嵌入式端：规则分类（轻量，实时性好）
- PC 端验证：SVM / 随机森林

## 遇到的难点

1. **信号稳定性差** — NFC 工作距离 < 10cm，信号波动大，需要滑动窗口平滑
2. **实时性要求** — 动作识别延迟控制在 100ms 以内
3. **泛化能力** — 不同用户、不同标签的信号差异，需要足够的训练数据

## 技术收获

- NFC 协议栈（ISO 14443）深入理解
- STM32 SPI 驱动开发
- 信号处理从理论到实践
- 端侧轻量推理的实现思路
