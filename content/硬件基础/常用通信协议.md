# 1 常用通信协议对比

SPI、I2C、UART 是嵌入式三大基础协议，选对能省很多事。

## 1.1 一图总览

| 特性 | SPI | I2C | UART |
|------|-----|-----|------|
| 线数 | 4 (SCLK/MOSI/MISO/CS) | 2 (SCL/SDA) | 2 (TX/RX) |
| 双工 | 全双工 | 半双工 | 全双工 |
| 速率 | 几十 Mbps | 100k / 400k / 3.4M | 波特率可配 |
| 拓扑 | 一主多从 | 多主多从 | 点对点 |
| 应答 | 无 | ACK/NACK | 无 |
| 距离 | 短 (<30cm) | 短 (<1m) | RS485 可达 1200m |

## 1.2 SPI — 追求速度

适合高速外设：Flash、屏幕、ADC/DAC。

```
主机 → SCLK: 时钟
主机 → MOSI: 主出从入
主机 ← MISO: 主入从出
主机 → CS:   片选（每从机一根）
```

- 时钟极性 (CPOL) + 相位 (CPHA) 组合出 4 种模式，双方必须一致
- 无 Ack 机制，靠时钟同步，速度快但引脚开销大
- 多从机 = 多根 CS 线

## 1.3 I2C — 引脚紧张时用

适合传感器、EEPROM 等低速设备。

- 每个设备 7 位地址，总线上挂多个设备只需 2 根线
- 开漏输出必须接上拉（通常 4.7kΩ）
- 通信流程：START → 地址 + R/W → 数据 → STOP
- 总线仲裁支持多主机

## 1.4 UART — 最简单的点对点

适合调试串口、蓝牙/GPS 模块通信。

- 无时钟线，双方约定波特率（常见 9600 / 115200）
- 数据帧：起始位 + 数据位 + 校验位 + 停止位
- TTL 电平，远距离需转 RS232 / RS485

## 1.5 选型一句话

**速度优先 → SPI，引脚有限 → I2C，点对点/调试 → UART，工业/长距离 → CAN 或 RS485**
